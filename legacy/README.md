# Historical compatibility source

This directory contains earlier DUBSAR workflow experiments retained for
compatibility tests, migration analysis, and provenance review.

Nothing under `legacy/` is included in the public package inventory or exposed
by the Codex, Claude Code, or Cursor manifests. It is not an alternative setup
path and should not be copied into host profiles.

The supported product starts at the repository [README](../README.md), with the
current storage contract documented in
[`docs/MEMORY_ARCHITECTURE.md`](../docs/MEMORY_ARCHITECTURE.md).
