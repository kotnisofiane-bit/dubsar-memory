# Conceptual provenance boundary

This public implementation was written independently after an internal review
of earlier continuity and memory experiments. No source file from those systems
is copied into this repository.

The public product retains only generic ideas: immutable snapshots,
append-order records, explicit absence, exact relations, bounded artifact
lifecycle states, and advisory human guidance. It deliberately excludes
private topology, formulas, scoring, ranking, posture, governed replay, and
execution authority.

Memory Guidance v2 is read-only. It derives one action, memory state, artifact
lifecycle, and bounded exact relations from the same inspected snapshot. It
never activates a host tool, selects work, or reads personal memory.

The implementation is therefore an independent public continuity product, not
a port or public edition of an internal engine. Similarity review and human
provenance approval remain release gates for packaged distribution.
